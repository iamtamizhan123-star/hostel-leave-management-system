# HLMS — Hostel Leave Management System

A polished, responsive, front-end prototype for a college hostel's sequential leave approval workflow.

## Run it

Open `index.html` in a browser, or serve the repository with any static web server. No build step or backend is required for the demo.

## Demo accounts

The login screen provides demo controls for Student, Class Tutor, HOD, Dean, Deputy Chief Warden, Chief Warden, Principal and Administrator. Data is held in browser memory for this prototype.

## Included

- Responsive navy, white and sandal/gold interface
- Role-aware dashboards and navigation
- Student leave submission, profile and application timeline
- Sequential tutor → HOD → optional Dean → Deputy Warden → optional Chief Warden → Principal workflow
- Parent verification simulation and urgent-leave authorization record
- Admin workflow settings, user management, audit log and reports views
- Notifications, status badges, search-ready tables and mobile layout

The prototype deliberately does not make real phone calls or send real notifications. It is structured so its state and actions can later be connected to authentication and a database.
